# 卓越计划（Great Plan）

[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)
[![GitHub Stars](https://img.shields.io/github/stars/onefl666/dsh-great-plan)](https://github.com/onefl666/dsh-great-plan/stargazers)
[![GitHub Issues](https://img.shields.io/github/issues/onefl666/dsh-great-plan)](https://github.com/onefl666/dsh-great-plan/issues)

一个 DSH Web 插件：在执行计划前选择模型与思考强度，并支持直接执行、压缩上下文后执行，或在新会话中清空上下文执行。

## 功能

- **执行计划**：批准计划，在当前会话中按所选模型继续执行。
- **压缩上下文并执行**：先压缩计划之前的历史，再原地批准。
- **清空上下文并执行…**：停止当前回合，在同一工作区新建会话，把本次 plan 模式期间的用户指令与已批准计划作为首条消息执行；可选择 Agent 模式，旧会话保留。
- **极简模式运行环境**：新会话选择内置 **极简模式** 时，首条消息还会附带工作区目录、系统平台、当前时间/时区，并注明旧上下文已清空，用于弥补极简预设被抑制的运行时上下文。可在插件设置页关闭。
- **头脑风暴式计划**：需求有会改变方案的歧义时逐轮提出一个简短问题；信息足够后给出简要依据、重要权衡和明确假设（建议性约束）。可在插件的设置页关闭，证据链与交接提示仍保留。
- **无限 Token 预算提示**：plan 模式与新会话执行时，提示模型 token 预算无上限，不要为节省用量而减少调研、工具调用或必要提问（建议性约束）。可在插件的设置页关闭。
- **卓越计划设置页**：在原生「设置」面板中增加一页，提供 **注入头脑风暴提示词**、**注入 token 预算无上限提示词**、**携带原始用户指令** 与 **极简模式下附带运行环境** 四个开关（默认开启）。计划提示词开关在下次生成计划时生效，新会话开关在下次执行时生效。
- **证据优先的计划**：plan 模式下要求计划包含背景、证据链和交接说明（建议性约束）。
- **首条消息预览与本次执行开关**：「清空上下文并执行…」确认前，浮层会预览新会话首条消息的实际内容：执行说明、可选的预算提醒、可选的极简运行环境、原始用户指令（含条数与字符数）以及已批准计划，并显示总字符数与估算 tokens。预算、指令、运行环境三个开关只影响本次执行，不修改全局设置。超过约 32,000 字符会显示超大提示，指令永不截断。
- **可恢复的压缩失败**：压缩无法进行（后端不可用、无可压缩历史、请求失败或取消）时不再自动批准计划，浮层会说明原因并提供 **重试压缩**、**仍然执行**、**取消**。浮层内的失败文案已本地化。
- **浮层内查看计划与返回修改**：无需关闭浮层即可展开完整计划；「返回修改」等价原生 Discuss（隐藏审核卡、计划仍待审）。遮罩会压暗页面。
- **模型搜索与提供商默认强度**：模型列表可按提供商或模型名过滤；思考强度列表可随时清除显式覆盖，回到「提供商默认」。
- **恢复默认**：设置页中处于关闭状态的开关会提供「恢复默认」按钮，写回默认值（开启）。

原生的 **Approve**、**Request changes**、**View full plan** 保持不变；插件只在计划审核卡上增加一个 **执行选项** 入口。

## 要求

- 带 Web 客户端的 DSH，0.2.1-rc.3 或更新版本（已在 0.2.1-rc.5 验证）。
- **压缩上下文并执行** 需要 DSH 组合中有 compaction 后端；没有时浮层会显示失败，可选择重试、仍然执行或取消。

## 安装

通过 `plugin_manager` 的 `install_bundle` 安装本目录，target 为包目录的绝对路径。安装后插件在 Plugins 列表中显示为 **卓越计划**。

## 使用

1. 用 `/plan` 进入 plan 模式，让 Agent 提交计划。
2. 审核卡出现后，点击 **执行选项**。
3. 可选：选择模型与思考强度。选择会立即应用到当前会话，并与 Composer 模型选择器一致。
4. 选择执行方式：
   - **执行计划**：直接批准。
   - **压缩上下文并执行**：先压缩。压缩不可用、无可压缩历史、请求失败或被取消时不再批准计划：选择 **重试压缩**、**仍然执行** 或 **取消**。运行中关闭浮层会取消等待。
   - **清空上下文并执行…**：查看首条消息预览与本次执行开关、选择 Agent 模式后确认。新会话会携带已批准计划（以及你保留的原始指令与极简运行环境）；消息发送后旧会话停止但保留。
5. **返回修改** 隐藏审核卡并回到输入框提出修改，行为与原生 Discuss 一致；**执行计划** 等价原生 Approve。

## 设置

在侧边栏打开 **设置**，选择 **卓越计划**。**注入头脑风暴提示词** 控制 plan 模式提示词是否要求澄清与头脑风暴；关闭后仍保留证据链与执行交接要求。**注入 token 预算无上限提示词** 控制 plan 提示词与「清空上下文并执行…」首条消息中的预算提醒；关闭后只移除该提醒。**携带原始用户指令** 控制是否把 plan 模式期间的用户文本按时间顺序带入新会话。**极简模式下附带运行环境** 控制极简预设的新会话是否附带工作区目录、系统平台、时间与清空说明。四个开关默认开启，由 Host 保存，刷新后保持。处于关闭状态的开关还会显示 **恢复默认**，通过同一配置表单写回默认值（开启）。

## 命令

`/great-plan-compact` 压缩待审核计划之前的历史。**压缩上下文并执行** 会自动调用它；它也会出现在命令菜单中，不接受参数。

## 已知限制

- 模型列表已提供简单子串搜索；完整选择仍用 Composer 的模型控件，两者不共享状态。
- 选择模型会按 DSH 既有行为同时保存为默认模型。
- 压缩会产生一次摘要模型请求。
- 新会话标题前缀与旧会话停止均为 best-effort。
- 浮层打开时，原生 **Approve** / **Request changes** 位于浮层之后；请先关闭浮层（或使用「返回修改」，等价 Request changes）再操作原生按钮；浮层内的「执行计划」就是 Approve。
- 中文界面下，对话中的命令结果卡片仍为英文（Host 命令契约没有 locale）；浮层内的压缩失败文案已本地化。
- 预算、头脑风暴与证据提示均为建议性约束，插件不校验模型是否遵循；命令描述不支持多语言。设置开关依赖 DSH 的 settings 服务；不可用时该页不会注册，四个开关均按默认开启处理。
- 无限预算提醒只加入 plan 模式提示词与「清空上下文并执行…」首条消息；「压缩上下文并执行」不会添加该提醒。设置界面不可用时，客户端按默认开启处理新会话开关。
- plan 模式用户指令从旧会话已加载的事件窗口读取；插件最多回看 8 个历史页寻找当前 plan 模式起点，找不到时回退当前回合或最后一条用户文本。预览读取的结果会复用于执行。指令永不截断：预览会显示总字符数、估算 tokens，超过约 32,000 字符给出超大提示，但极长的对话仍会产生很大的首条消息。
- 预览中的极简运行环境在进入清空视图时读取；执行时会重新读取时间，因此预览时间可能与实际不同。
- 极简模式运行环境从浏览器读取（平台、本地时间与 IANA 时区）。远端 Web 部署中它描述的是浏览器环境，不一定等于 Host；工作区目录仍来自 Host 侧工作区。
- 新会话使用部署默认的权限与沙箱上下文，不继承旧会话的权限或沙箱状态。
- 「清空上下文并执行…」在发送提示词前会复核审核是否仍待处理，并在消息发送后停止旧会话。其他客户端仍可能在这段短暂窗口内批准同一审核，因此多客户端残余竞态未完全消除；若审核结算已导致浮层关闭，后续失败只会写入浏览器控制台。

## 开发

无构建步骤、无安装依赖。Host 半会导入几个由运行中的 DSH 安装提供的包（`@deepseek-ai/schemastery`、`@deepseek-ai/dsh-compaction`），已在 `peerDependencies` 中声明。运行 gate（语法检查 + host 测试）；`PATH` 中没有 node 时会自动使用 DSH 自带的 Node：

```bash
bash tools/gate.sh
```

gate 通过只说明语法与离线测试正常，不代表 GUI 行为正确。同一 gate 在 CI（`.github/workflows/gate.yml`，Node 24）中随 push 与 pull request 运行。修改 Host 后需重启 DSH；修改 Client 后 touch `client.js` 并刷新页面。架构、GUI 手工清单与约定见 [AGENTS.md](AGENTS.md)。

## 项目结构

| 路径 | 作用 |
|---|---|
| `index.js`、`host/` | Host 半：`/great-plan-compact` 命令与 plan 模式提示词段 |
| `client.js`、`client.<name>.js` | Client 半：入口及 `ui`、`settings`、`model`、`preset`、`actions`、`panel` chunk |
| `locale/` | Plugins 列表的标题与描述 |
| `test/`、`tools/gate.sh` | 离线测试与验证 gate |
| `.github/workflows/gate.yml` | CI：push 与 pull request 时运行 gate |

详见 [AGENTS.md](AGENTS.md) 的 Module Map。
